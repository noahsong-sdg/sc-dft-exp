# Bind the proposed correction before a material action

A unit direction is insufficient: its candidate, source inverse and actual scale
must remain associated. prepare_correction_direction.py creates a separate input
artifact without changing the accepted gap or any frozen parent.

The guarded preparation revisits the inverse's own directory for its frozen
source/build/full-residual validator, restores its owner directory, and replays
all inverse arithmetic independently. It checks the exact public/consumed
manifest, terminal receipt/guard/deadline/resource fields, recorded/raw readback,
output hashes and parent input closure. This prevents an old or differently
normalized correction from silently entering the next microscopic test.

The output binary contains exact candidate bytes followed by correction/h,
where h=maxabs(correction). Four-line metadata binds counts/beta/operator;
full-map-step.in records h. A separate recipe records the inverse manifest/result,
source correction hash, candidate hash, output hashes and measured maxabs(h*v-c).
Neither a gap update nor a response/conditioning certificate is produced.

Tests cover payload roundtrip, candidate/input preservation, normalization and
rounding, stale/changed receipt/guard/deadline/output/readback/arithmetic,
consumed-manifest mismatch, invalid context/scale/nonfinite state and padding.
Canonical temporary paths are used for macOS's /var-to-/private/var alias; real
owning paths retain exact identity checks.246tests PASS29.327s,237Python
compilations and moment replay PASS; no separate typecheck.
