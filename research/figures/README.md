# Figure provenance and interpretation

Generated by `research/plot_response.py` using matplotlib 3.9.4/numpy 2.0.2.
Run `.venv/bin/python research/plot_response.py` from repository root after the
bounded retrieval. Source URLs/hashes are in ../retrieval_manifest.json.

Underlying data: Kawamura, Nomoto, Witt and Arita's public V3Si release,
https://doi.org/10.1103/lrhl-j9bt , linked at https://mkawamura.ynu.ac.jp/data/ .
These are new plots/diagnostics, not copied publication figures.

released_response: left uses the archived plot's conversion of reported current
to A/cm²; right compares origin-constrained fits over the first 1–4 nonzero
samples, colors shared with the left legend. Those windows may include physical
nonlinearity. Their spread is not an error bar or proof of the Q->0 limit. The
released zero-Q point is processed as zero; raw code's projected current is
undefined there. No corrected material current is shown.

extraction_routes: reproduces archived script+plot conversions for both methods.
The 1 K slope is 97.60 nm, close to the published 97 nm; peak route is 177.09 nm
versus published 136 nm, still unresolved. Sampled maxima and nearest half-gap
points are used exactly as in the archived script, without new interpolation.
This is a reproduction diagnostic, not independent experimental validation.

Both PDF vector and PNG raster versions are provided. Axes/legends were visually
inspected on the response figure; they render without clipping at output size.
