# Saved-response analysis

Run from the repository root with Python 3.9+ (standard library only):

```
python3 research/response_analysis.py fetch
python3 research/response_analysis.py analyze
python3 -m unittest discover -s research -v
```

Downloads are bounded to 1 MB each and remain ignored pending redistribution
rights review. `fetch` prints URLs, byte counts, retrieval time and SHA256 hashes.
The committed manifest records the first retrieval. Remote files are mutable;
compare hashes before treating a new download as the same evidence.

Analysis reproduces the author's xi.sh single-point penetration-depth conversion
and compares origin-constrained linear fits over the first 1–4 nonzero samples.
Those fits are diagnostics of finite-window sensitivity, not estimates with
certified error or proof of the asymptotic slope. Large windows may include
physical nonlinear response. No statistical confidence intervals are implied.

## Initial observation

Seven V3Si curves contain 10–20 samples each. At 1 K the author's script formula
on the current public processed file gives 184.44 nm, not the paper's table value
97 nm. This mismatch remains unresolved: release version, extraction protocol,
units, averaging, functional and temperature choices need tracing. Do not call
it a paper error or use this value as a reproduced published prediction.

At 1 K, fitting two rather than one nonzero sample changes the inferred length
ratio to 1.1065, and four samples to 1.4511. This could include genuine nonlinear
response; it does not establish numerical uncertainty. The two-point ratios at
3–15 K range from 1.0146 to 1.1023. Raw-current reconstruction and analytic
conversion checks are the next gate before any solver computation.
