# Saved-response analysis

Current correctness follow-up: [RHS thermal finding](RHS_THERMAL_FINDING.md) now
includes the complete gap-RHS assembly fixture. Run its networked native check
with `python3 research/full_rhs_probe.py --blas /path/to/libblas.a`; it requires
gfortran and a compatible double-precision BLAS library. These synthetic routines
are distinct from the staged [material preparation pilot](PREPARATION_PILOT.md).

Run from the repository root with Python 3.9+ (standard-library Python;
the complete regression suite also requires gfortran):

```
python3 research/response_analysis.py fetch
python3 research/response_analysis.py analyze
python3 -m unittest discover -s research -v
```

The suite includes the [complete symmetry-routine regression](SYMMETRY_SCALE_FINDING.md),
which requires gfortran and runs without network access. Some older scalar tests
can skip without the compiler; those skips do not establish native validation.

Run `python3 research/full_current_probe.py` with network access and gfortran
to retrieve a SHA256-checked pinned source, extract its complete unmodified
supercurrent routine, compile with small synthetic modules, and compare four
weighted-state cases against direct thermal identities. Source stays in a
temporary directory; no third-party source is redistributed. Assertions account
for upstream's five-significant-digit output precision. This is not a full QE
build or material simulation.

Downloads are bounded to 1 MB each and remain ignored pending redistribution
rights review. `fetch` prints URLs, byte counts, retrieval time and SHA256 hashes.
The committed manifest records the first retrieval. Remote files are mutable;
compare hashes before treating a new download as the same evidence.

Analysis reproduces the author's xi.sh single-point penetration-depth conversion
and compares origin-constrained linear fits over the first 1–4 nonzero samples.
Those fits are diagnostics of finite-window sensitivity, not estimates with
certified error or proof of the asymptotic slope. Large windows may include
physical nonlinear response. No statistical confidence intervals are implied.

## Initial observation

Seven V3Si curves contain 10–20 samples each. At 1 K the author's script and plot
conversion give approximately 97.60 nm, close to the paper's table value 97 nm.
The initial 184.44 nm diagnostic omitted the plotting script's multiplicative
Bohr conversion (0.529177249). That was an error in our analysis, now corrected
and covered by a regression comparison with the independently archived xi.dat.
The remaining sub-nm difference is not yet attributed to rounding or protocol.

At 1 K, fitting two rather than one nonzero sample changes the inferred length
ratio to 1.1065, and four samples to 1.4511. This could include genuine nonlinear
response; it does not establish numerical uncertainty. The two-point ratios at
3–15 K range from 1.0146 to 1.1023. Raw-current reconstruction and analytic
conversion checks are the next gate before any solver computation.
