# Start here

The reusable fourteen-day campaign prompt is
[TWO_WEEK_GOAL_PROMPT.md](TWO_WEEK_GOAL_PROMPT.md). Use it when that campaign is
started; writing the prompt does not itself schedule continuous execution.

Read [PROJECT_SPEC.md](PROJECT_SPEC.md) and [RESEARCH_LEDGER.md](RESEARCH_LEDGER.md)
before continuing research. They hold the user's autonomous research mandate,
resource limits, acceptance gates, and restart state. README benchmark snapshots
are historical unless freshly verified.

Separate verified evidence from inference. Trace execution paths and root causes
before code changes. Make the smallest coherent fix; preserve unrelated work.
Add meaningful regression tests for bugs, including stale data when relevant.
Run narrow checks during iteration and required build/typecheck at final gate.
Report exact checks. Keep PRs single-purpose and under 700 non-test code lines.
Do not delegate to subagents unless explicitly authorized. No outreach or paid
compute. Relevant public progress publication is authorized, subject to privacy
and redistribution rights. Follow the project spec rather than expanding scope.
